幕 1 · token 界面 · 编解码器与词表

模型的全部输入输出,是整数序列

  • 自回归模型的全部输入输出是整数序列 ——第一层是嵌入查表 ,最后一层在 V 个 id 上做 softmax。
  • 整个中间过程对「id 背后是什么」一无所知:一个 id 代表英文子词还是四帧动作,是词表约定,不是模型结构。
于是让一个 GPT「多模态」,机制上只需两件事:
(1) 每模态一个 tokenizer(文献亦称 codec)
tokenizer 与 codec 是同一个东西——都指这一对「编码器 + 解码器」映射本身,不包含后面的自回归模型。T′ = token 的个数(64 帧经下采样,本例 T′ = 16,幕 3);K = 每个 token 的取值种数 = 这一模态自己的词表大小(动作例 K = 512)——并进共享词表时,它就是 V 里宽 K 的一段 band(下页)。对文本这就是 BPE(课 3);对连续信号,是幕 3-4 要构造的神经网络。
(2) 一个共享词表
把各模态的 token 排进同一 id 空间的不同区段(band)。(下页)

幕 1 · token 界面 · 有损

连续 tokenizer 必然有损

  • BPE 是离散到离散的:字节序列 ↔ token 序列可以无损往返。
  • 连续信号的 tokenizer 是连续到离散的:不可数集映到有限集,压缩必然有损——
右边总共只有 种可能的 token 序列;不可数的输入映到有限种输出,必然多对一——被合并掉的差别,就是损失。
先感受压缩量:原始 64×139 个 float32 = 35.6 KB/窗口;目标 16 个 token、每个 9 bit = 18 字节/窗口。
这么强的压缩之所以可能:人体运动远远填不满 139 维——关节角强相关、时间平滑、动力学有规律,数据住在一个低维流形附近。把这个流形找出来,是自编码器(幕 3)的工作。

幕 3 · 压缩机器 · 自编码器

自编码器:在重建目标下学一个低容量瓶颈

自编码器(autoencoder)是一对神经网络:编码器 把输入压成瓶颈量 z(= "latent"),解码器 D 再从 z 还原。训练目标是重建输入:
让 z 的信息容量远小于 x,即为压缩。三种正交的手段,后文都会用到:
  • 降时间分辨率:64 帧 → 16 个潜时间步;
  • 降维:每步向量维度低于输入维度;
  • 离散化(VQ / FSQ,本幕后半):潜向量只允许取有限个值——这是压缩的主体,且不依赖前两条。VQ 路线甚至把维度升上去,压缩全部由离散化承担。
特例:若 E、D 都取线性映射且瓶颈降维,最优解恰是 PCA(投到前 d 个主成分);非线性自编码器是它在流形上的推广。

参考架构:一维卷积栈的形状走查

本讲通篇使用一个具体的动作 tokenizer:一维卷积栈 + 步长下采样 + 残差块,约 18M 参数——与 T2M-GPT 的动作 VQ-VAE、SoundStream 音频 codec 同型。两层步长 2 的卷积把 64 帧下采样 4 倍到 个潜时间步。
编码器(下采样)
输入 x [B, 64, 139] 转置 [B, 139, 64] Conv1d 139→512 k4 s2 [B, 512, 32] Conv1d 512→512 k4 s2 [B, 512, 16] 残差块 ×N k3 s1 [B, 512, 16] 1×1 投影到瓶颈 d [B, d, 16]
解码器(镜像上采样)
z [B, d, 16] 1×1 投影 [B, 512, 16] 残差块 ×N [B, 512, 16] ConvTranspose1d ×2 [B, 512, 64] 1×1 投影 + 转置 [B, 64, 139] (重建 x̂)
为什么用卷积而非 MLP:卷积核只看局部时间邻域、权重沿时间共享——匹配"动作的局部规律处处相同"这一先验,也让同一网络适用于任意长度序列。

压缩的度量是信息容量,不是维度;码本坍缩

"维度去哪了?"
VQ 的典型设置 ,潜空间几何维度比输入(139)还高——根本没降维。但压缩的正确度量是信息容量:量化后这个 512 维向量只能是 K 个码字之一,携带 ,与维度 d 无关。

有效码本远小于 K(极端时 512 码只几十个在用),码率名不副实。监控:码使用困惑度 (满码本均匀使用时 )。

幕 5 · 表示的选择 · 旋转流形的拓扑

SO(3) = 半径 π 的实心球,对径点粘合

  • 3 维紧致李群:9 个矩阵元受 6 个正交约束,剩 3 个自由度。
  • 直观模型:群元由实心球内的点表示——点到球心的距离 = 转角 θ(≤ π)、方向 = 转轴 𝐧;球心 = 单位元。
  • 球面上的对径点粘合:绕 𝐧 转 π 与绕 −𝐧 转 π 是同一旋转。
  • SO(3) 不同胚于 ℝ³(紧致 vs 非紧),也不同胚于 S³(后者单连通)。

幕 5 · 表示的选择 · 经典参数化的病灶

欧拉角 / 轴角 / 四元数——奇点都来自那个拓扑

欧拉角(依次绕三轴转的 3 个角)
本质是给 SO(3) 铺一张 ℝ³ 坐标卡;紧致群铺不平非紧的 ℝ³,一张卡盖不住全群,必有奇点。表现为 gimbal lock:中间角到 ±90° 时第一、三轴重合,丢一个自由度,附近参数剧烈跳动。
轴角(指数映射的逆,)
在 θ = π 处不唯一:π𝐧 与 −π𝐧 是同一旋转(正是上页的对径粘合),连续性在边界破坏。
单位四元数
q 与 −q 给出同一旋转: 是二对一的双覆盖。要在整个 SO(3) 上连续地为每个旋转选定一个代表(取 q 还是 −q),做不到。
回路论证:沿转角从 0 连续增到 2π 的一条回路(在 SO(3) 里回到单位元),其在 S³ 上的连续提升满足 ——终点是起点的负号。代表必在中途换号,回归目标出现不连续点。

幕 5 · 表示的选择 · 连续表示的下界

要处处连续,维数必须 ≥ 5:6D 是最朴素的解

定理(非正式)[Zhou et al. 2019]
对 SO(3),任何进入 维及以下欧氏空间的表示对 (f, g)(满足 g∘f = id),其编码 f 必在某处不连续; 维时存在处处连续的表示(论文给出 5D 与 6D 的显式构造)。
6D 表示 = 取旋转矩阵的前两列:
网络输出的是 6 个自由实数,读成两个向量 ——它们不会自觉满足「单位长、互相垂直」的约束,必须先修正成合法旋转才能使用。这个修正过程就是解码,用 Gram-Schmidt 正交化完成,任意不共线的一对输入都能修:
g 在 ℝ⁶ 的一个稠密开集上良定、光滑;f 连续、无歧义(旋转矩阵唯一,不存在「选代表」)。实验上 6D 在姿态回归中系统性优于四元数与欧拉角 [Zhou et al. 2019],已是动作生成的默认选择之一。
用几个数表示一个旋转是工程决定,而它的答案由流形的拓扑裁定——拓扑性质在此直接决定网络的输出表示。

幕 5 · 表示的选择 · 训练的最后一块

tokenizer 训练的最后一块:损失在哪个空间算

到这里,tokenizer 的构造已经齐了:编码器 → 量化(VQ / FSQ)→ 解码器;训练 = 重建损失(VQ 另加码本两项)。还差最后一块:重建损失在哪个空间算?
最直接的选择是 139 维特征上的 MSE。但特征误差不直接等于看得见的动作误差——132 个数是旋转的 6D 坐标,其余是位置与高度,同样大小的数值误差落在不同通道,后果完全不同。运动的失真应在几何空间(FK 之后的关节位置)度量,标准选择是 MPJPE(mean per-joint position error,单位 cm):
FK 对局部旋转可微,损失可以穿过 FK 反传——在关节角上训练、在空间位置上监督。至此,tokenizer 的构造与训练全部就位。

  • 表征(幕 2、5):一帧 = 139 实数(22 关节 × 6D 旋转 + root 通道);旋转写成 6D——由 SO(3) 的拓扑裁定。

幕 6 · 生成质量的度量 · 排除两个候选

重建的失真度量不够——生成模型的输出是分布,要能给分布打分

同一段文字可以对应多种合理动作。两个乍看现成的候选,都不能当裁判:
候选一:动作 token 上的交叉熵(课 3)
  • 码流的熵是 tokenizer 自己造的——换一个 tokenizer,同样的动作产生统计性质完全不同的码流,数字之间没有共同的尺子,不能跨 tokenizer 比较。
  • tokenizer 有损:完美预测了 token ≠ 还原出的动作好。质量最终要在信号空间(FK 之后的几何)里衡量。
候选二:连续信号上的最大似然
  • 生成器是「解码器 + 采样」的形态:能采样、算不出密度,这个罚分根本无法计算。
  • 它是局部的:只读真值点处的密度,对质量摆在哪里全盲。例:真值 y = 0,模型 A 全部质量在 0.1、模型 B 在 10,两者同罚 +∞,而我们显然要 A ≫ B。
需要的尺子:在关节位置空间中(而不是 token 空间)、给分布打分(而不是给单个采样)、只需采样就能算(而不是需要分布密度)、且能分辨多峰(而不是鼓励拟合均值)。

幕 6 · 生成质量的度量 · 与课 2 的和解

课 2 说交叉熵「唯一」——那个证明用了一条公理:局部性

课 2 的博弈:自然持分布 p,你宣布 q,抽到结果 Y 罚 ;最优策略 = 如实报告。推出「罚分只能是 −log」的那一步,有一条隐含假设:罚分只依赖你押在实际结果上的那一个数 qY——其余概率怎么摆,它一概不看。这条公理叫局部性(locality):
定理 [Bernardo 1979]
在「局部」公理之内,交叉熵确实唯一(仿射等价意义下)。
  • energy score 不在这条定理的管辖范围:它不是局部的——贴近项与自距离退款都要遍历你宣布的整个分布;同样的 qy,质量摆得近还是远,罚分不同(本幕开头 δ0.1 vs δ10 的例子)。
  • 公理为什么换:token 世界没有度量,「错得远近」无定义,局部性零成本——交叉熵唯一胜出;几何空间里「错得近要罚得少」,逻辑上必须看真值以外的质量分布——必须放弃局部性。放弃之后,严格适当的评分是一族,energy score 是对多维连续量最实用的一员。
两个「唯一」不矛盾:给定罚分,最优报告唯一(= 诚实;交叉熵与 energy score 都满足);满足诚实的罚分本身,只在选定公理后才唯一——局部 ⇒ 交叉熵;几何敏感 + 只需采样 ⇒ energy 家族。

幕 7 · 前沿:动态码率 · 固定码率的代价

主流方案把「每单位时间花多少表示容量」当作常数

机械臂
Diffusion Policy、ACT(固定控制频率的动作块)、π0(流匹配、固定频率)、RT-2 类 VLA(固定粒度动作 token)、VQ-BeT(残差 VQ 码化)。
动作生成
T2M-GPT、MotionGPT,工作在固定 fps、固定每 token 比特数的动作码流上。
但任务对精度的需求在时间与部位上高度不均匀:抓取的最后一厘米、插接对准的瞬间需要毫米级控制;大范围转移动作不需要。人类自身即如此——Fitts 定律[Fitts 1954]:达点时间随目标精度要求对数增长,精细化只发生在需要的自由度与时段上。
固定码率范式下想要局部精细,只能整条轨迹加密——为 1% 的关键时段,付 100% 时段的高码率成本。
