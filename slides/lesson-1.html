用它说话

推理：输入一行，输出一行——只读一格

输入： BABCABAAAAA ← 后 5 格随便填（全填 A）
输出： xxxxxCxxxxx → 下一个字母：C（99.9%）
x = 不关心——那些列的输出这次用不上；紫框 = 唯一要读的一格：前缀最后一个字母所在的位置。
  • 推理没有换机器：还是一次算出所有 11 个位置的输出——但只读一格：B A B C A B 读到 B 为止的那一列 → C。
  • 生成循环：把 C 接上 → 输入变成 B A B C A B C ＋ A A A A → 这次读第 7 格 → A → ……（live：让它一直说下去，永不犯规。）
  • 为什么敢全填 A？位置 i 只看 ≤ i（前面那条结构规则）——右边流不进来。实测：填 AAAAA / BBBBB / CCCCC，读数的三个概率小数点后六位一致（0.999081）——可用 minimal_gpt 自己验。

主体的约定

从这里开始：11 个向量进，11 个向量出

  • Embedding 之后，主体的每一站都是 11 个 48 维向量进、11 个 48 维向量出——形状 (11, 48) 全程不变。
  • 站内允许临时变形——attention 会造出一张 (11, 11) 的表、MLP 会加宽到 192 维——但出站前必定变回 (11, 48)。
  • 除 attention 外，每一站都是对 11 个向量独立施加同一个变换——向量之间互不影响；attention 是唯一让它们相互作用的站。
  • 所以每一站只需要回答一个问题：它怎么改这 11 个向量。　每页顶部的"形状带"，就是这一站的签名。

第三站 · 附

Softmax：一列数，变一列概率

真实一列（推理页紫框那一格，模型实际算出的数）：
(A, B, C) 的 logits　(−2.44, −1.65, +5.72) ──softmax──▶ (0.03%, 0.06%, 99.91%)
  • 指数化 → 全变正数；归一（除以总和）→ 和为 1：一列任意实数，就变成一列概率。
  • 减掉 max(x) 只为数值稳定，结果一个都不变（省得指数爆炸）。
这台机器里它出场两次：attention 的每一行（刚刚见过）、Output 的每一列（终点站见）。

第四站

多头：同一件事，并行做两份

2 × (T, A) ──拼接──▶ (T, C) ──W_o [C×C]──▶ (T, C) ──⊕ 加回
nano：2 × (11, 24) → (11, 48)　W_o[48×48]
2 个头，各自把完整的 48 维输入投影成 24 维 → 拼回 48 → 混合 → 加回。
同一个 48 维输入，经两套不同的投影，各得一个 24 维——不是把 48 切成两半。
参数量与头数无关——3 头改 2 头，85,728 分毫不变。

第五站

MLP：每个位置自己的加工厂

(T, C) ──[C×4C]──▶ (T, 4C) ──GELU──▶ (T, 4C) ──[4C×C]──▶ (T, C) ──⊕ 加回
nano：48 → 192 → 48
11 个 48 维向量进 → 11 个 48 维向量出；每个向量独立（位置之间在这里不说话）。
Φ = 标准正态的分布函数；模型里实际算的是右边的 tanh 近似（minGPT 原样——minimal_gpt.py 里就这一行）。
attention 在位置之间搬信息，MLP 在位置内部加工信息。

softmax · 一个旋钮

温度（temperature）：softmax 上的一个旋钮

softmax 有个标准写法（相当于 τ=1）；我们把它改一下——logits 先除以 τ，再 softmax。
温度 τABC
0.2566%34%0%更尖 → 更集中
1.054%46%0%模型原本的分布

τ 越小 → 柱子越尖（极限：一根吃掉 100%）；τ 越大 → 越平（极限：均匀）。

推理 · 循环生成

推理：反复「取一个字，贴回去」

B A B C A B → 模型 → C （规则：A,B 之后必 C）
B A B C A B C → 模型 → A （规则：C 之后必 A）
B A B C A B C A → 模型 → A / B ？ （自由位·各半）
… 一直接下去 …
每一步：整条序列喂进去 → 模型给出下一个字 → 贴到末尾 → 再喂进去。序列一步步变长。
这就是 autoregressive（自回归）生成。前两步规则说了算；第三步是自由位，取 A 还是 B？——下一页。
每一步都是一次完整前向；上下文越来越长（真模型里，这是推理的主要开销）。

推理 · 采样

每一步取哪个字：贪心 = 温度 0

循环里每一步，都要从那列概率取一个字。其实是同一件事——只是温度不同：
贪心：τ = 0
旋钮拧到底 → 永远取最高那根
采样：τ > 0
按柱子高矮「掷骰子」抽一个
自由位「B A」之后，模型说 A 54% / B 46%：
贪心 → 永远 A → 输出 A A A A… 单调重复　｜　采样 2000 次 → A 1073 / B 925 → 有 A 有 B，还原真实的 50/50
自由位本就该「有时 A、有时 B」——采样才对得起分布；贪心（τ0）只会永远给 A。
确定位（A,B→C 押 99.9%）两种取法都给 C，没差别；差别只出现在有随机性的地方。
