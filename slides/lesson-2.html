第二课 · 训练
幕 0 · 训练模式

一次前向，11 格同时答题——凭什么能这样？

  • 喂一句 (B,T)，一次前向就吐出 (B, T, V) = (64, 11, 3)：每一格一份"下一个字"的猜测分布。
  • 每格都有现成答案（正下方那个绿字），所以一句 = 11 份训练信号，一个 batch = 64×11 = 704 份。
凭什么 11 格能同时训、还不算作弊？—— 因果 mask：第 i 格只能看 ≤ i 的字。预测第 3 格时它看不到第 4 格的答案，所以把 11 格并排一次算完，完全合法（这正是上一课那张 mask 图，在训练里的意义）。
模型现在吐出的，是它的猜测 q；我们手里有答案。
怎么量"猜得多差"、怎么把 q 逼近答案？—— 训练的目标函数：loss 函数。
第二课 · 训练
幕 1 · 什么是好

一个游戏：你给对答案的概率越高，罚得越轻

规则（就看一个位置）：
  • 庄家手上有个真分布 p——下一个字本该怎么分布。 例（自由位）：p = (A 50%,  B 50%,  C 0)。
  • 玩家（模型）先报出猜测分布 q——那一格的 softmax。 例：q = (A 53.2%,  B 46.8%,  C 0)。
  • 庄家按真分布 p 抽出下一个字 Y，只按玩家压给 Y 的那点概率算罚：
  • 反复无数次。 压对了给高概率 → 罚轻；给它低概率却被抽到 → 罚重。 玩家的目标：最小化惩罚。
  • 最优策略：报 q = p。
这就是 cross-entropy loss（交叉熵）——"照真分布诚实报"的唯一自洽罚则。
第二课 · 训练
幕 1 · 什么是好

Output 那一格的 softmax，是一个学出来的分布

# 确定位　"B A B"（A,B 之后必是 C） q = ( A 0.03% , B 0.06% , C 99.91% ) ← 模型赌注 A : -log 0.0003 = 8.1 B : -log 0.0006 = 7.4 C : -log 0.9991 = 0.0009 真分布 p = ( 0 , 0 , 100% ) # 庄家按它抽 # 反复无数次，加权罚： 0·8.1 + 0·7.4 + 1·0.0009 = 0.0009
# 自由位　"B A"（自由，A/B 各半） q = ( A 54% , B 46% , C 0.03% ) ← 模型赌注 A : -log 0.54 = 0.62 B : -log 0.46 = 0.78 C : -log 0.0003 = 8.1 真分布 p = ( 50% , 50% , 0 ) # 庄家按它抽 # 反复无数次，加权罚： 0.5·0.62 + 0.5·0.78 + 0·8.1 = 0.70
同一个模型：确定位加权罚 → 0.0009（赌对了）；自由位加权罚 → 0.70，压不下去。它学到的是分布——该尖的尖、该平的平。
自由位这个 0.70 到底是什么数、为什么压不下去、整段训练的地板由它怎么定——下一幕「那个下不去的地板」揭晓。
第二课 · 训练
幕 1 · 什么是好

整个 batch 的 loss = 每一格罚值的平均

logits (B, T, V)  +  答案 (B, T)  →  每格一个罚  →  全部平均  →  一个标量 𝓛
N = B×T = 64×11 = 704 个罚，取平均。这一个数，就是"当前模型有多差"。
训练 = 把这一个数压到尽可能低。
注意：词表大小 V 就是 Output 层的宽度——玩具里 V=3，真语言模型里 V 是几万。

幕 1 · 为什么偏偏是这个 loss

换个想法：不预测分布，直接回归一个值？

  • 把 A / B 当成数（0 / 1），让模型只吐一个数 ŷ，用最眼熟的均方误差罚它：
  • 看起来更省事——一个数、一个平方差，和你拟合抛物线时一模一样。
确定位（A,B→C）它没问题。灾难出在自由位。
第二课 · 训练
幕 1 · 为什么偏偏是这个 loss

自由位：ŷ 被逼进山谷，一个永不发生的答案

MSE 把 ŷ 拉到两个峰的平均 ½——可 ½ 既不是 A 也不是 B，落在山谷里，每次都错。
在运动模型里就容易犯这样的错：训练集里有各种动作轨迹，L2 回归却给你「站着不动」。
多峰的未来，用一个点去拟合，必然塌成均值——一团模糊。
第二课 · 训练
幕 1 · 为什么偏偏是这个 loss

分布能说「两者各半」，一个点不能

回归一个点（MSE）
报 ŷ = 0.5
= 说谎：0.5 永不发生，每次都错。
预测分布（CE）
报 q = (½, ½)
= 诚实：如实说 A / B 各半。
单峰目标都行；多峰目标，只有分布不塌。
两条独立的论证同指 CE：① 它是唯一能逼出 q=p 的罚（黑板上证）；② 它罚在分布上，不是点上（多峰）。
这也预告了两件事：自由位的地板正是这个双峰分布的熵（幕3），以及生成时为什么要采样（推理课）。

第二课 · 训练
幕 2 · 怎么降

关键一步：本地导数，要在前向的具体取值上求值

链式里的每个因子，拆开只有三类——而"在哪个数上求值"就决定了"要存什么"：
是个函数 → 得代入前向那个具体的  →  存
就是这层的输入  →  存 （最底层是 x）
就是权重本身  →  本来就在手里
导数是在前向那趟的具体数值上算出来的——要反向，前向的中间量（）必须攥着。下页：这就是训练吃显存的根。
第二课 · 训练
幕 2 · 怎么降 · 第一次撞上 infra

一次回传拿到全部梯度 —— 靠 forward 存、backward 取

  • 一次就够：从右往左，每个上游 只算一次、一路复用 → 一次回传 ≈ 一次前向，就拿到全部 8.5 万个梯度（朴素法得扰动每个参数、跑 8.5 万次前向）。
  • 靠什么做到：forward 顺手把每层中间值（）存下来，backward 逐层取用——必须先存、才能倒着取。
开关：requires_grad=True（训练）→ 存中间值；  torch.no_grad()（推理）→ 什么都不存，算完即弃
这些为反向留住的中间值，AI 里就叫 activation（激活值）——其实就是"中间值"。
推理只要权重 → 省；训练要攥住整袋 activation → 吃显存得多。这就是第一个 AI infra 问题。
精确显存账（权重＋梯度＋优化器态＋activation）要引入优化器，留 infra 周——今天只立住"中间值必须存"这件事。

训练要多少算力？—— 每参数每 token 6 FLOP

第一课精确数的 N（非嵌入），就为估这个。一次"乘＋加"= 2 FLOP：
一步分量式FLOP
前向 2N
反向·对输入 2N
反向·对权重  （沿 batch/token 维 t）2N
前向 2N ＋ 反向 4N ＝ 6N / token → C ≈ 6ND。
嵌入是查表、不做乘加 → 不进 N（第一课"计算量看非嵌入 N"）。权重梯度那个 是 batch 累加——正是反向第 2 个 2N 的来处（单 token 会退化成 1N）。

幕 2 · 怎么降 · 立刻用起来

现在你能估：这块卡，能训多大的模型？

Chinchilla 经验法则：把模型「喂饱」，训练 token D ≈ 20 × 参数 N（代进 6ND，得中间那步）。
给定算力预算 C → 反解能训多大的 N；反过来定住 N，就求出时长。
算力预算 C ＝ 峰值算力 × 卡数 × 时长 × MFU，其中 MFU ≈ 40%（峰值打四折）。
每张卡峰值（BF16）：RTX 5090 ≈ 210 ｜ A800 ≈ 312 ｜ H100 ≈ 990 TFLOPS。
硬件配置时长能训模型 N训练 tokens（≈20N）
2 × RTX 5090（消费级）1 天≈ 350 M≈ 7 B
2 × A80030 分钟≈ 60 M （≈ GPT-2 小号）≈ 1.2 B
80 × H100（8卡×10机）≈ 4 小时2 B40 B
80 × H100≈ 17 小时4 B80 B
80 × H100≈ 2.8 天8 B160 B
看最后三行：参数翻倍 → 时间 ×4（4h → 17h → 2.8天）。算力吃的是 N²——大模型为什么这么烧钱，就在这。
参数都在上面，下表每行可自行验算——量级估算，只抓算力主项，不含显存 / 通信 / 数据工程。
第二课 · 训练
幕 2 · 怎么降 · infra 优化空间

backprop 不是死公式——存 / 算的颗粒度可选

① 存 vs 重算
全存 = 反向快、显存大；只存少数"存档点"、其余反向时重算 = gradient checkpointing。拿算力换显存。
② 粗 op vs 细 op
把整块（如整个 attention）当一个 op、手写反向＋内部重算 = 算子融合 / FlashAttention：省显存又快。
存什么、重算什么、多粗的 op 求导——一整片可调空间，就是 AI infra。

整个训练，核心就 四行

for it in range(max_iters): # 一遍一遍地来 x, y = get_batch(...) # 取 64 句 logits = model(x) # 前向：每格吐出 logits（softmax 前的原始分数） loss = cross_entropy(logits, y) # 一个数：当前多差 opt.zero_grad() # ① 清掉上一轮的梯度 loss.backward() # ② 反向传播：算 85,728 个偏导 clip_grad_norm_(..., 1.0) # ③ 给梯度设个上限（防炸） opt.step() # ④ 每个参数走一小步

第二课 · 训练
幕 3 · 那个下不去的地板

打开黑箱：地板 = 自由位的 ln2 = 掷硬币的熵

模型看到的上下文下一个字占比实测平均罚理论
刚出现 C必是 A（确定）22.7%0.0020
刚出现 A,B必是 C（确定）21.9%0.0010
自由位A / B 各半（掷硬币）55.4%0.695ln2
确定两类 → 罚压到 0；自由位真分布是公平硬币 (½,½)，最优也只能报它 → 罚 = ln2 = 这枚硬币的熵（不可约随机性）。
总地板 0.385 ＝ 55.4% × ln2 ＝ 自由位占比 × 掷硬币的罚
换算成"选择数"：exp(loss)（perplexity，AI 行话）= 平均每个 token 有几种有效选择。自由位 exp(ln2)=2（A/B 五五开）；整个地板 exp(0.385)≈1.47。
硬币结果不可预测——不是模型不够好，是信息本身不在。下一课 scaling law：把地板整体压低。

为什么非得分两步？—— 生肉免费，标注贵

只做 postrain（直接教它当助手）
得从零、全用贵的人工标注灌满——想让它什么都会，标注量是天文数字，灌不动。
pretrain ＋ postrain
pretrain 数据 ＝ 生肉网页（万亿 token）＝ 基本免费（下一个字白送）。
postrain 数据 ＝ ~几万条人写样本 ＝ 贵，但小。
免费的海洋先学会「语言 ＋ 世界怎么运转」，贵的一小撮只需教「该怎么表现」。
所以 next-token 这个看着「怪」的目标，是整个 LLM 的地基——它不用一条人工标注，就能吃下整个互联网。
postrain 也顺带做对齐（有用 / 无害）；但「省标注」是它最初、也最硬的道理。

玩具没有、真东西必须有的两样

要让 pretrain 吃下整个互联网，靠这两样——也正是你玩具里最简陋的两处：
① Tokenizer（切字）
玩具：3 个字母，规则手写死。
真东西：几万个 BPE token——常用词整块、生僻词拆片，怎么切直接决定序列多长、词表多宽。
"strawberry" 到底是 1 个 token 还是 4 个？模型能不能数对 r，从这一步就定了。
② 数据管线（喂数据）
玩具：get_batch 当场生成 64 句。
真东西：TB 级语料要清洗、去重、打乱、分片，还要不停歇地喂满 GPU——喂慢了，卡就在空转烧钱。
很多时候瓶颈不是算力，是数据喂不够快。
这两样 + 前面的 GPU 异构、分布式、显存账，合起来就是 AI infra——第二三周的主场。今天先让你看见玩具和真东西之间隔着什么。
