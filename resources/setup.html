沙盒与 Claude Code 搭建指引

课上演示的那套工作环境，本指引教你在自己电脑上搭一遍。 需要 sudo 的步骤（装软件）自己动手，照着下面敲；不需要 sudo 的（写脚本、build 镜像、排错）尽管让你的 AI 助手代劳。 遇到问题先把报错原文贴给 AI，再问同学/助教。 本指南默认你的网络能正常访问 GitHub、npm 等站点；网络有困难的同学请咨询同学或助教。

0. 为什么要沙盒

让 AI agent 真正提效的用法，是放手让它干活：装依赖、改文件、跑实验、自己调试。但在你自己的系统里放开手脚是危险的——它一条命令走错，你的系统就没了。

解法：给它一个容器当沙盒，容器的边界就是权限的边界——在容器里它想干什么干什么（我们会直接打开"跳过所有权限确认"模式），折腾坏了就把容器扔掉重来。真正要保护的产物（代码）放在挂载目录里，用 git 管理。

1. 两档任务

档位 完成标准
基础 装好编辑器 + Claude Code，接通一个后端，用它完成破冰任务（梯度下降拟合抛物线，逐行追问到全懂）
完整 建好 Podman 沙盒（含 Mathematica 挂载，必做）；在沙盒里让 agent 完成一件小事并 git commit

2. 准备 Linux 环境

  • Linux：直接下一步。
  • Windows：装 WSL2（管理员 PowerShell）：wsl --install -d Ubuntu-24.04，重启后进入 Ubuntu；之后所有命令都在 WSL 的 Ubuntu 终端里执行。
  • macOS：brew install podman && podman machine init && podman machine start，后续步骤相同。

3. 编辑器 + Claude Code + 后端（基础档）

  1. 装一个带集成终端的编辑器：VS Code 或 Cursor 都行（Windows 同学：编辑器装 Windows 版，终端连 WSL）。装这几个插件： - Claude Code（Anthropic 官方插件——装了它就不必单独装命令行版） - Dev Containers（容器化开发用；⚠ 这条路用微软 VS Code，Cursor 的同名 fork 与 podman 不兼容） - Git Graph（可视化提交历史） - Remote - SSH（连远程机器才需要）
  2. （可选）命令行版 Claude Code——想在纯终端里用才装，用插件的同学跳过：

bash curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash - sudo apt-get install -y nodejs git python3 python3-pip sudo npm install -g @anthropic-ai/claude-code

  1. 接通一个后端（三选一）： - Claude 官方（需订阅，国际支付）：启动 Claude Code，按提示登录。 - DeepSeek（人民币）：照官方指南 → https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code - 智谱 GLM（人民币，Coding Plan）：照官方指南 → https://docs.z.ai/scenario-example/develop-tools/claude

  2. 基础档验收：用 Claude Code（插件或终端）完成破冰任务。

4. 装 Podman（需要 sudo，手动）

sudo apt update
sudo apt install -y podman uidmap slirp4netns fuse-overlayfs git
podman run --rm docker.io/library/hello-world     # 验证：能拉镜像、能跑

为什么用 rootless Podman：容器里的"root"经映射只是你的普通用户——agent 在容器里怎么折腾，落到你系统上都是无特权的。这是"放心全开权限"的根据。

5. 装 Mathematica（必做，需要 sudo，手动）

  • 从学校正版软件渠道装好 Mathematica 并激活（自行获取；装到默认位置 /usr/local/Wolfram）。
  • 沙盒不重装、不重新激活——下一步的脚本会把宿主安装只读挂进容器。原理：Wolfram 授权按机器 ID 验证，机器 ID 来自 /etc/machine-id，所以要把它也挂进去，容器里的授权才和宿主一致。
  • 为什么必做：科研工作流里"读文献 → 符号验证"这一环靠它——课上演示的那个循环。

6. 构建镜像 + 安装启动脚本（不需要 sudo，可让 agent 代劳）

~/Containerfile：

FROM docker.io/library/ubuntu:24.04
RUN apt-get update && apt-get install -y --no-install-recommends \
        ca-certificates curl git python3 python3-pip build-essential \
    && rm -rf /var/lib/apt/lists/*
RUN curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt-get install -y nodejs
RUN npm install -g @anthropic-ai/claude-code
WORKDIR /work

podman build -t agent-base -f ~/Containerfile ~

~/bin/task-sandbox（chmod +x，确保 ~/bin 在 PATH；<版本> 换成你机器上 ls /usr/local/Wolfram/Wolfram/ 看到的版本号）：

#!/usr/bin/env bash
set -euo pipefail
SRC="$(realpath "${1:?用法: task-sandbox <项目目录> [镜像]}")"
IMG="${2:-agent-base}"
podman run --rm -it \
  -v "$SRC":/work:rw \
  -v claude-cfg:/root/.claude \
  -v /usr/local/Wolfram:/usr/local/Wolfram:ro \
  -v /etc/machine-id:/etc/machine-id:ro \
  -v "$HOME/.Wolfram/Licensing/mathpass":/root/.Wolfram/Licensing/mathpass:ro \
  -e WOLFRAM_EXEC=/usr/local/Wolfram/Wolfram/<版本>/Executables \
  -w /work \
  "$IMG" bash

7. 进沙盒干活（完整档）

# 编辑器打开项目目录；集成终端里：
task-sandbox ~/projects/你的项目
# —— 现在在容器里 ——
IS_SANDBOX=1 claude --dangerously-skip-permissions
  • --dangerously-skip-permissions：agent 的动作不再逐条确认。只在容器里这么用——篱笆是容器，不是你的克制。
  • IS_SANDBOX=1：容器内是 root，Claude Code 默认拒绝 root 下开全权限；这个官方变量声明"我在沙盒里"。
  • agent 改的文件在编辑器里实时可见（宿主和容器看同一批文件）；退出容器即焚，项目目录里的产物保留；git commit 勤一点。
  • Claude 登录态存 claude-cfg 卷，换容器不用重登。
  • 把随发的 sandbox-setup-brief.md 放进项目目录：沙盒内外的 agent 读它就能秒懂环境。
  • 想在 IDE 里直接容器内开发：让你的 agent 按简报 §2B 给项目配 .devcontainer，用微软 VS Code 的 Dev Containers 打开（Rebuild and Reopen in Container）。
  • 完整档验收：沙盒里让 agent 用 wolframscript 验证一个积分（如 Integrate[Sin[x]^2,x]），把结果写进 README，git commit。

8. 语音输入（推荐）

和 agent 的大量交流，用嘴比用手快。推荐 OpenTypeless（开源，自行搜索安装）或付费版 Typeless。装好后对着输入框说话——你会回不去的。

9. 安全清单（容器不替你挡的事）

  1. 只挂任务需要的目录。容器保护你的系统，不保护你主动喂进去的数据——挂进去的目录 agent 就能改能删，靠 git 兜底。
  2. 别把私钥、密码、token 放进挂载目录（~/.ssh 绝不要挂）。
  3. 只想让它读的东西，挂载加 :ro。
  4. 想彻底断网跑：起容器时加 --network none。

10. 常见坑速查

症状 处置
WSL2 里 podman 报 systemd/cgroup 错 /etc/wsl.conf 加 [boot] systemd=true；PowerShell wsl --shutdown 后重进
拉镜像 / npm / pip 慢 换国内源：TUNA（apt、pip）、npmmirror（npm）——让你的 agent 代劳
容器里 Mathematica 报"未激活" 三条挂载少了 /etc/machine-id（见 §5 原理）
claude 每次要重新登录 起容器时漏了 -v claude-cfg:/root/.claude
容器里 root 却不能 cd 挂载目录 查 ~/.config/containers/containers.conf 是否设过全局 userns——删掉
