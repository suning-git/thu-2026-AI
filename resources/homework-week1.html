2. 破冰：让 AI 带你写一次梯度下降

让你的 AI 助手带你写一个小脚本：用梯度下降拟合一条抛物线 y = ax² + bx + c，画出拟合结果和 loss 下降曲线。

  • 代码可以完全由 AI 写，但你要逐行追问，直到每一行都能讲给别人听。
  • 这就是整门课的工作方式：AI 动手，你监督到每一行。

3. 背诵：nano-gpt 的完整计算流（7/8 第二次课前）

打开课程版 LLM Visualization（地址课后发到课程群——课上演示的那个、学的是三字母语言的 2 头版本；公网 bbycroft.net/llm 是旧的 3 头排序版，结构相同但任务不同），把里面 nano-gpt 的整个计算过程背下来。

  • 为什么要背：① 这是你们最基本的思考素材——Transformer 的这些设计，很多要素最终可能出现在真正的 AGI 里；背下来，才能在这个基础上思考还需要什么。② 这是理解 Transformer 的最短路径——以"背下来"为目标，你会自动识别出每个 building block。
  • 自检标准：闭上眼睛，把整个可视化从 Embedding 到 Output 重放一遍，每个箭头都说得出流过去的东西是什么形状。
  • 背下来还有个用处：之后和任何人讨论模型，你能问"你改了哪里"，并有能力验证对方的说法。

随作业发放：minimal_gpt/ 文件夹——课上那个模型的单文件 PyTorch 版 + 训练脚本 + 权重（和网页里是同一份，数值可逐一对上）。全程只需 CPU；--trace 模式是背诵自检的好工具，改它重训就是周日 ablation 的起点。用法见文件夹内 README。

4. 读代码 + 算力：读懂 minimal_gpt（第二次课后，周日 Hackathon 前）

第二次课讲了反向传播和算力账，这一项让你在代码里把它们坐实：

  • 阅读 minimal_gpt/ 的代码，逐行弄清楚——每一步在做什么、张量形状怎么走。
  • 熟悉反向传播：对照第二次课，看代码里梯度是怎么一次反传就把所有参数的梯度都拿到的。
  • 算力，实测 + 手算对照：
  • 测：给前向 / 反向计时，量出实际计算耗时；
  • 算：用第二次课的方法算出训练一步的计算复杂度（每 token 约 6N），再和实测对照。

完成时间：周日 Hackathon 之前。
