课程目标

课程结束时，你应当能从头训练一个真实的语言模型，读懂它的每一步，并具备改进架构、探索 scaling law 所需的工程能力。课程彻底动手，每个概念都落到能跑的代码上；三次 Hackathon 让你完整走一遍想法 → 实现 → 实验 → 读曲线 → 下结论，用 scaling law 做客观检验。鼓励组队——1–4 人一组、共享算力，把一个项目一起做完。

上手怎么学这门课

材料都在下方"资源"区，上手的主干只有四步，按顺序走；之后的专题（第四课起）按兴趣挑。

步骤做什么过关判据
0 · 搭环境照环境指引装好，跑起第一周材料包里的 minimal_gpt它能对输入文本给出下一个 token 的预测
1 · 背熟结构盯着 3D 可视化看、对照 minimal_gpt 的代码；第一课补齐规则凭记忆画出完整数据流，标出各处形状
2 · 训练真模型学第二课、第三课，用 nanoinfra 在真实语料上训练训出自己的 loss 曲线，复现 scaling law
3 · 做一个消融fork 消融实验合集，照模板只改一个成分、与原版对照向合集提一个 PR：对照曲线 + 你的结论

建议全程让 AI 当你的工程助手——示范见第五课的 Vibe Coding 现场实录。走完这四步就算上手，剩下的专题按兴趣选。

大纲课程内容

一 · 预训练

理解并从头训练一个大语言模型。

  • Transformer：MLP / attention / residual stream / RoPE / tokenizer
  • 训练基础：loss / 反向传播 / optimizer / 自回归范式
  • 训练工程：PyTorch / 数据管线 / 分布式（FSDP）/ 算子
  • Scaling law：推导 · 实验设计 · 实测与拟合

二 · 后训练

从预训练模型到可用的助手。

  • SFT（监督微调）+ LoRA
  • 强化学习

三 · 多模态与前沿

当前 AI 研究的前沿方向与开放问题。

  • 多模态：动作模型 / 视频 / Diffusion
  • 多模态理解与生成的统一、loop model 等
